-Extendemos información de la clase pasada sobre qué son:
	-API: concepto general de comunicación entre aplicaciones.
	-REST: arquitectura orientada a recursos, ideal para servicios CRUD y APIs web tradicionales.
	-RPC: modelo orientado a ejecutar funciones remotas, muy utilizado en sistemas distribuidos y rendimiento
	
	-Características entre REST y RPC:
		-Caract. Conceptualmente
			-REST: recurso
			-RPC: método/procedimiento

		-Caract. Ejemplo:
			-REST: user/10
			-RPC: getEpochInfo

		-Caract. uso típico de HTTP
			-REST: get, post, put, delete
			-RPC: post
	
		-Caract. parámetros
			-REST: URL/body/query
			-RPC: params

		-Caract. Operación
			-REST: trabajar implícitamente con HTTP/URL
			-RPC: usar explícitamente el método

		-Caract. Respuesta
			-REST: normalmente es un JSON
			-RPC: objeto tipo JSON-RPC
